# Звук запуска

Компонент `src/components/effects/StartupSound.tsx` ожидает файл ровно по
этому пути:

```
public/sfx/fl-studio-startup.mp3
```

Я не могу сам скачать и вшить конкретный звук запуска FL Studio в проект —
это чужой авторский аудио-ассет, и подходящей легальной версии для
автоматической загрузки у меня нет. Что нужно сделать вручную:

1. Возьми звук запуска FL Studio (или любой другой короткий "студийный"
   звук, который тебе нравится — на будущее это может быть свой собственный
   sfx) в формате mp3, желательно 1–3 секунды, без длинной тишины в начале.
2. Положи файл в `public/sfx/fl-studio-startup.mp3` (папку нужно создать,
   если её нет).
3. Всё остальное уже готово: после того как отработает Loader, звук
   проигрывается один раз за сессию. Если браузер заблокирует автозапуск
   со звуком (это стандартное поведение Chrome/Safari до первого клика),
   компонент сам доиграет его при первом клике/тапе/нажатии клавиши —
   ничего дополнительно настраивать не нужно.

Если хочешь другой путь или имя файла — поменяй константу
`STARTUP_SOUND_SRC` в `StartupSound.tsx`.
