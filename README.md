# baneoff — портфолио саунд-продюсера

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:3000. Админка — на `/admin` (пароль задаётся переменной окружения
`ADMIN_PASSWORD`, по умолчанию `baneoff`). Для аудио-аплоада и сохранения контента нужен
Vercel Blob (`BLOB_READ_WRITE_TOKEN` в `.env.local`) — без него сайт всё равно работает
на дефолтном контенте из `src/lib/i18n/content.ts`.

```bash
npm run build   # прод-сборка
npm run lint    # eslint
```

> В песочнице, где готовился этот архив, не было доступа к npm-реестру, поэтому
> `npm install` / `npm run build` не запускались локально. Код проверен вручную и
> точечно через `tsc` (без node_modules — это отдельная проверка синтаксиса, не полная
> сборка), но перед деплоем стоит один раз прогнать `npm run build` и `npm run lint`
> у себя, чтобы поймать возможные мелочи из-за версий пакетов.

## Что изменилось

**Архитектура** — секция Philosophy убрана полностью (текст, нумерация, переходы).
Порядок теперь: Hero → About (01) → Portfolio (02) → Contact (03). Число marquee-полос
сокращено с трёх до двух, чтобы убрать пустые провалы между блоками.

**Hero** — новый заголовок с чёткой связкой «кто я / зачем со мной работать», подзаголовок,
основной CTA («Обсудить проект» → скролл к контактам) и вторичный («Послушать работы» →
скролл к портфолио), trust-строка «20+ завершённых релизов».

**Portfolio** (бывший Work) — список превратился в сетку карточек с 3D-tilt hover,
жанром, тегами используемых инструментов, услугами (Сведение/Мастеринг/Продакшн) и
иконками-ссылками на Spotify/Apple Music/YouTube/SoundCloud на уровне трека. Управляется
из админки (вкладка «Портфолио»).

**About** — длинные абзацы заменены на короткий текст + список из трёх акцентных пунктов,
статистика осталась.

**Contact** — крупный CTA-баттон, строка «обычно отвечаю в течение дня», блок соцсетей
(Telegram/Instagram/SoundCloud/Spotify — подставляются только заполненные ссылки).

**SEO** — `robots.ts`, `sitemap.ts`, `manifest.ts`, JSON-LD (Person + ProfessionalService +
WebSite) в `src/components/effects/JsonLd.tsx`, полные Open Graph/Twitter метаданные,
canonical URL, favicon/apple-icon/OG-картинка генерируются на лету через `next/og`
(`src/app/icon.tsx`, `apple-icon.tsx`, `opengraph-image.tsx`) — так не нужны бинарные
файлы иконок в архиве. Не забудь поменять `siteUrl` в `src/lib/i18n/content.ts` на
реальный домен.

**Производительность** — `next.config.ts` включает `compress` и современные форматы
изображений на будущее; `prefers-reduced-motion` теперь по-настоящему глушит анимации
(было объявлено, но не работало для transition/scroll-triggers); фокус-стили добавлены
для доступности и Lighthouse a11y-score.

**Полировка** — в `globals.css` добавлены единые токены `--radius-sm/md/lg` и
`--shadow-card` для последующей унификации карточек/кнопок.
